# ⚛️ React Website

A web application built with React.js, created to explore modern frontend development and build an interactive user experience.

**[🌐 Live Demo](https://react-website-project.firebaseapp.com/)**

## ✨ Overview

React Website is a frontend development project built using React. It demonstrates the fundamentals of developing a web application with reusable components, a structured project layout, and a modern JavaScript development workflow.

## 🛠️ Tech Stack

| Technology | Purpose |
| --- | --- |
| React.js | Building the user interface |
| JavaScript (ES6+) | Application logic |
| HTML5 | Page structure |
| CSS3 | Styling and layout |
| Create React App | Development and build tooling |
| Firebase Hosting | Hosting the live website |

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/VincentGuo25/react-website.git
```

**2. Navigate to the project directory**

```bash
cd react-website
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The development server automatically reloads when you make changes to the source code.

## 📜 Available Scripts
